Run audit mode of the `carousel-design` skill on the screenshots the user attached. Arguments: $ARGUMENTS

- Audit only the user's own posts. Ask for the screenshots if none are attached, cover first and in order, and stop.
- Report the seven errors (small text, wrong ratio, generic design, crowding, static cover, random structure, repeated call to action) and the slide count; transcribe the copy and run the text gates on it.
- Judge by sight. Never use Arabic OCR to decide anything, and never score or compare another person's post.
- End with the top three fixes and an offer to rebuild the post in the Studio.
