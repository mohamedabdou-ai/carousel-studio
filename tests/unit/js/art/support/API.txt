==========================================================================================================

  CS.art.register(kind, builder, subs) requires a nonempty string[]; registration is atomic.
  A second owner of ANY (kind, sub), including duplicates in one call, throws E_ART_DUPLICATE.
  Invalid registrations throw E_ART_REGISTER. Earlier builders always keep ownership. There is no wildcard registration.
  CS.art.has(kind, sub?) checks exact sub support (omitting sub asks whether kind exists).
  CS.art.build(anchor, ctx) dispatches by _.sub(anchor), returns null for absent support, and propagates builder errors.
  _.sub: icon -> icon; scene -> template || solo; chart/mock -> anchor[kind].kind; pattern -> anchor.pattern;
         numeral -> companion || none; word -> wordStyle || solid; rows -> list;
         field -> value ? numeral : word ? word : (icon || object) ? icon : panel.
  Numeral data is anchor.value / anchor.unit. anchor.numeral is not supported.
  CS.art.caps() -> {v:1, art:{kind:[sub...]}}; keys and subs sorted, fresh snapshots, only registered pairs.
  CS.visual.art.caps() delegates or returns empty art when cs-art is absent.
  CS.visual.caps() -> {v:1,art,recipes,variants,types,tones,hash}; available recipes: under over full center;
     variants: stat icon/chart, compare table/before-after, quote statement, rehook statement, step track,
               cta action, item numeral, grid bento, timeline rail; all 20 types; tones base/invert/field.
     hash = fnv1a64(canonicalJSON(payload without hash)); sorted-key JSON, integer manifest, independent of DOM.
     Pass caps explicitly to plan(spec, brand, preset, memory, {caps}). No registration or capability lookup reads document.

What the kit reads from ctx (IS-3). Everything has a neutral default, so a half-filled ctx still builds.
  ctx.tokens  { bg surface ink inkMuted accent accent2 onAccent line note, support: [hex, hex] }   hex strings, tone-resolved
              kit.palette(tokens) adds: tint (the accent mixed toward the surface until ink reads on it at 4.5:1; on a dark ground the surface itself), paper (= surface),
              and falls back for missing roles (support: accent mixed toward ink / surface). Memoised per tokens object.
  ctx.art     { stroke (24-unit), cap, join, container: square|disc|hand-circle|stamp|app-tile|arch, radius { chip tile card panel window },
                shadow { kind: none|hard|soft, dx, dy, blur }  <- an OBJECT, not a CSS string, outline (px), wobble, tilt, mark: fill|outline, badge?, fills? { chip, tile, ... } }
              fills is optional: a role name or hex per treatment (chip tile sticker duo badge giant). kit.dna(art) completes it. Memoised per art object.
  ctx.id = ctx.slideId, ctx.rules = CS.core.registry.rules() for compose.label.
  ctx.rtl (default true), ctx.seed, ctx.slideId, ctx.box { w, h, x?, y? }, ctx.zone, ctx.recipe, ctx.size, ctx.labelsOnly.
  ctx.slide: deeply frozen copy of {id,type,title,kicker,headline,sub,body,bullets,sides,number:{value,unit},quote,
             attribution,items,demo:{lines,caption},sourceIds}; ctx.visual = slide.visual.
  ctx.brand: null | {handle,name,art}; ctx.sources: {id:shortLabel}; ctx.data: {pack,objects,marks}; ctx.tone.
  Production hooks (E2a) supply this context; support/page.js supplies the same shape for isolated builder tests.
  ctx.tokens is the complete, resolved tokens.tones[tone] bundle: bg surface ink inkMuted accent accent2 onAccent line support note.
  Box = {x,y,w,h,kind:text|ink|owner|pattern|image|mark|decor,id?,ownerOf?,fill?,border?,anchor?,path?,ground?}.
  Coordinates are px in the body zone, origin ctx.box.x/y (0 when absent); fill is opacity 0..1, border is px,
  path is [[x,y],...], anchor and ground are booleans. Builders never read layout or mutate ctx.slide.

CS.art.icon(name, o) -> <svg class="cs-icon"> | null          .full(name, o) -> { el, w, S, pad, g, fill, glyph } | null          .measure(o) -> measure() without drawing
CS.art.object(id, o)  -> <svg class="cs-icon"> | null          .full(id, o)    .ids(o)
  o: ctx | tokens + art + rtl + seed;  size: xs..hero or px (icons default md, objects lg);  treatment: bare chip tile ring duo sticker badge giant (objects also sticker = die-cut);
     stroke (24-unit, still laddered), drawOn (glyph paths get pathLength=1, data-m=stroke, data-m-i), mirror (flips the glyph only), modifier | badge: slash cross plus check question sparkle
     (none | unknown draws nothing), fill (role or hex of the container), glyph, ink, ground (what the knock-out and badge sit on; default the container fill, else bg), tintFill (duo, giant),
     outline, paper, lift (true | false | hard | soft), tilt, name (seeds the sticker tilt and the hand circle), base (objects: the base role), pack / objects (inject data; else the block
     cs-icon-pack / cs-icon-objects through CS.visual._.block).
  The svg is S + 2 pad square: the visible container is the centred S square, pad covers outline, paper keyline, lift, tilt and the hand wobble. Nothing draws outside the svg (tested).
  Glyph in 24-unit space; closed subpaths in f take the tint (duo, giant) and are painted first; dots (s) are r = 1 circles grown to the stroke's diameter; every stroke is path-only (A14).
  The lift (hard 6 x 6, soft 0 12 32 ...) is the DNA's value at lg and above and shrinks to half at xs and sm (a 32 px blur under a 64 px chip is not a shadow any more); its direction follows rtl.
  Badge and sparkle: the accent unless it vanishes on its ground (1.8:1), then a support hue, then the ink; they sit inside the glyph box, so a bare icon needs no pad.

Anchors registered here (IS-3):  { kind: "icon" | "field", icon?, object?, captions?: [text], treatment?, size?, badge?, mirror? }
  treatment default: icon on a peak recipe (over center half full band) giant, else duo; object sticker (giant on a peak recipe); field sticker on the panel. size: the named token, else the
  largest whose container fits the box (caption line 56 + gap 24 included). A missing object falls back to the icon. The container is the owner (data-owner on the svg; for field the
  panel div). Returns { el, boxes, labels }: boxes owner / ink / text with ownerOf; labelsOnly returns { el: null, boxes: [], labels }.

Harness (tests/unit/js/art/harness.mjs) - see its header. Quick form:
  await withArt(async (art) => { const r = await art.render(anchor, { preset: "creator", tone: "base", rtl: true, box: { w: 852, h: 420 } }); (await art.safe(r)).violations; (await art.paintBoth(r)).ssim }, { data: "real" })
  node tests/unit/js/art/run.mjs [--only kit,registry] [--out DIR] [--real] [--final]
  --final forces shipped real icon data for every test and fails on core fallback, fixture/custom data or skipped tests. All runs exit nonzero on a skip or missing test.
  Each test clears the page body before running, including contact sheets outside #art-stage, so hit tests cannot sample a previous sheet.
  A test file default-exports {module,tests:[{name,real?,run(t)}]}; t = assertions + t.art.
  art.sheet({ cols, cw, ch, items: [{ kind: icon|object|anchor, name|id|anchor, opts, preset, tone, rtl, label, box }], title }) -> { sel, w, h }; art.shot(sel, "file.png"); art.small(png, width)
  art.mount((CS, ctx, arg) => node, arg, o) mounts any node a function builds (kit-level tests).
  safe(): A1-A6, A9-A12, A14-A17 and Arabic rules; A7/A8 source tests, A13 settle pass.
  A9: SUM over the nearest .cs-slide, else nearest .cell or [data-budget], else the supplied root.
  When checking a sheet, each cell has its own budget; cell markers inside a real slide never split its total.
  Includes svg roots and all nested/independent layers: <=800 SVG elements, <=24000 UTF-8 geometry bytes (path d and polygon/polyline points).
  A15: no overflow:hidden with any border/radius. A16: no inline background radius or inline box shadow.
  A17: matching role/preset/type/variant rules that set role font/colour properties need specificity >=(0,3,0), or inline styles.
  Scans style[data-cs-slide-css], style[data-cs-decor], and style#cs-archetype-css; tests inject decor overrides explicitly.
  art.paintBoth(slide,{regions:[selector,...]}) returns {svgPng,replayPng,ssim,regions:[{selector,svgPng,replayPng,ssim}]}.
  Use a complete slide AND art/label region selectors to avoid hiding local painter failures in a large flat background.
  --final checks the real core and pack; preset DNA here remains explicit spec test data, not production preset integration evidence.
  Without --out nothing is written; CS_TMP is the temp root (set it to keep Windows temp files in the session scratchpad).

Decisions A1 took (all reversible)
  1. Object sticker is a die-cut (a paper keyline that follows the silhouette) and not a container; the icon sticker is the container with the paper outline of 3.1.
  2. tint: accent mixed 62% toward the surface (ink must read on it at 4.5:1); on a dark ground (surface luminance < 0.2) it is the surface itself (a muddy khaki otherwise).
  3. creator-like DNAs (mark outline + disc container) fill chip, sticker and giant with the accent; swiss squares fill tile with the ink. art.fills overrides all of it per preset.
  4. The shadow shrinks with small glyphs (see above); modifier badges stay inside the glyph box.
